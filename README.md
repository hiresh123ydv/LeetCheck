# LeetCheck 🔥

> **AI-powered LeetCode profile roaster — in pure Indian tech-bro Hinglish.**

Enter any LeetCode username and get a brutally funny, data-driven roast of their profile stats — written like a classic Indian engineering senior at a chai tapri.

---

## ✨ What It Does

LeetCheck fetches your real LeetCode profile data and feeds it to an AI model that roasts:

- **Easy / Medium / Hard split** — are you actually solving problems or just farming Two Sum?
- **Submission count vs accepted** — treating LeetCode like a debugging console?
- **Contest rating & global ranking** — scared of Sunday 8 AM contests?
- **Submission streak & calendar** — daily 1 easy problem for "green box ki kheti"?
- **Badges** — participation trophies galore?

The roast is delivered in authentic Hinglish, punchy bullet points, and ends with a **Final Verdict**.

## 🚀 Getting Started

### Prerequisites

- Python 3.12+
- Node.js 18+
- A [Groq API key](https://console.groq.com/) (free tier available)

---

### Backend Setup

```bash
cd backend

# Install dependencies with uv
pip install uv        # if not already installed
uv sync

# Create your .env file
echo GROQ_API_KEY=your_key_here > .env

# Start the server
uvicorn app.main:app --reload --port 8000
```

The API will be live at `http://localhost:8000`.

**API Endpoints:**

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/` | Health check |
| `GET` | `/health` | Health status |
| `GET` | `/analyze/{username}` | Fetch LeetCode profile data |
| `GET` | `/roast/{username}` | Fetch profile + generate AI roast |

---

### Frontend Setup

```bash
cd frontend

npm install

# Optional: create a .env.local to point at a remote backend
# VITE_API_BASE_URL=http://localhost:8000

npm run dev
```

The app will open at `http://localhost:5173`.

> By default, the frontend calls the backend at the same origin (no `.env.local` needed for local dev when the backend is on port 8000 via the Vite proxy or you set `VITE_API_BASE_URL`).

## 🔐 Environment Variables

**Backend** — create `backend/.env`:

```env
GROQ_API_KEY=your_groq_api_key_here
```

**Frontend** *(optional)* — create `frontend/.env.local`:

```env
VITE_API_BASE_URL=http://localhost:8000
```

> ⚠️ **Never commit `.env` files.** They are excluded by `.gitignore`.
